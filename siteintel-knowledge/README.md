> 用于保存 SiteIntel 长期战略、产品方向、数据资产规划、商业化思路、AI 可发现性与子产品生态等跨版本知识。

- `03-SiteIntel-商业化与盈利模型.md`：商业化路径、客户类型、收入来源与风险

## 知识库原则

1. SiteIntel 2.0 大版本原则上收口，后续以 2.x 小规模迭代为主。
2. 网站查询是入口，不是最终商业终点。
3. 核心资产是长期积累的互联网实体、关系、历史变化、证据链与公开数据，而不是单个页面。
4. 所有公开数据必须区分来源、更新时间、可信度与适用范围；涉及版权、隐私及合规的数据不得默认进入产品资产。
5. 用户私有 Search / Investigation / Report 与公共网站情报必须严格隔离，公共数据尽量复用，避免重复检测。
6. 后续子产品优先复用 SiteIntel 已积累的数据底座，而不是重新建设独立数据采集体系。
7. SEO 与 AI 可发现性并行建设，但长期目标是形成可被机器理解、引用、调用的数据权威性。
