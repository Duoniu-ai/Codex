# SiteIntel 长期战略总纲

> 状态：长期方向 / 持续维护
> 建立时间：2026-08-26

## 1. 核心定位

SiteIntel 不应长期停留在“查网站用了什么技术”的工具定位。

长期目标是建设一个围绕互联网实体、企业公开信息、基础设施、技术、关系与历史变化的数据与情报基础设施。

一句话理解：

**网站是入口，企业是主体，关系是网络，历史是价值，情报是最终产品。**

## 2. 为什么从网站查询开始

网站查询具有天然低门槛：用户输入一个域名即可获得结果，适合获得第一批用户、建立 SEO 页面、验证数据采集链路，并持续扩大互联网实体数据覆盖面。

但单次网站查询本身商业价值有限，因此它应被视为：

- 用户入口
- 数据采集入口
- 实体识别入口
- SEO / AI 可发现性入口
- 后续情报产品的底层数据入口

## 3. 2.0 的战略原则

SiteIntel 2.0 大版本已经进入收口阶段，原则上不再为了远期想法大幅改变核心架构。

后续优先采用 2.x 小规模迭代：

- 补充数据资产
- 增加实体关系
- 增加历史变化
- 增加公开企业信息
- 增加可复用的媒体与品牌资产
- 增加机器可读能力
- 增加 AI 可发现性

避免为了“什么都能做”而不断破坏 2.0 已经稳定的核心能力。

## 4. 长期产品演进

### 第一层：Website Intelligence

- Domain
- Website
- Subdomain
- IP
- ASN
- CDN
- DNS
- Technology
- Infrastructure
- Security / network observations

### 第二层：Company / Organization Intelligence

- 公司名称
- 品牌
- 产品
- 公开联系方式
- 成立时间等公开信息
- 招聘与团队公开信号
- 公开业务信息

### 第三层：Entity Relationship

- 公司 ↔ 网站
- 公司 ↔ 品牌
- 品牌 ↔ 产品
- 网站 ↔ IP
- IP ↔ ASN
- 网站 ↔ 技术
- 公司 ↔ 子品牌
- 公司 ↔ 产品矩阵
- 组织之间的公开关联

### 第四层：Historical Intelligence

持续记录：

- 技术栈变化
- CDN / 基础设施迁移
- DNS 变化
- 网站改版
- Logo / 品牌变化
- 页面结构变化
- 新网站出现
- 新产品出现
- 国际化 / 出海信号
- 其他可验证的公开变化

### 第五层：Intelligence

在历史与关系数据之上产生：

- 企业成长信号
- 技术升级信号
- 扩张信号
- 出海信号
- 企业关联发现
- 行业趋势
- 相似企业 / 网站群
- 投资研究辅助信息
- 上市前公开互联网活动变化分析

注意：只基于合法、公开、可验证的信息，不把推断描述成企业未公开事实。

## 5. 数据资产优先级

1. 网站与基础设施
2. 技术与实体
3. 企业公开信息
4. 品牌与产品
5. 实体关系
6. 历史变化
7. 情报信号
8. AI 分析与预测

## 6. 用户数据边界

平台用户自身的账号、收藏、Search、Investigation、Report 等可以属于用户私有空间。

公共网站情报属于公共数据层，应尽量复用，避免因为用户权限隔离导致每个用户重复完整检测。

产品 UI 与数据模型应明确区分：

- 公开网站信息
- 我的分析
- 深度 / 私有情报

不能把一个用户的专属分析泄露给其他用户。

## 7. 长期商业愿景

最终不以“网站查询工具公司”为终点，而是逐步成为：

**互联网实体与企业情报的数据基础设施。**

产品形态可以包括 Web、API、企业平台、数据服务以及多个垂直子产品。

## 8. 长期判断

互联网入口会越来越 AI 化、平台化和实体化。静态网页本身的价值下降，而持续更新的数据、实体关系、历史变化与可信证据的价值上升。

因此 SiteIntel 应优先积累“机器可以理解、验证和复用的数据”，而不是单纯追求页面数量。
