# SiteIntel 商业化与盈利模型

> 状态：长期战略假设，需随市场验证持续修正

## 1. 基本判断

网站技术查询本身商业价值有限，不能把“查询一个网站”当作最终商业模式。

更合理的路径是：

**低门槛网站查询 → 数据积累 → 实体关系 → 历史变化 → 企业情报 → 数据服务 / API / 企业产品。**

## 2. 主要收入来源

### 2.1 专业会员

目标用户：

- 开发者
- SEO / 增长人员
- 产品经理
- 运营人员
- 研究人员
- 独立分析师

可提供：

- 更深的网站分析
- 历史记录
- 批量查询
- 收藏 / 监控
- 导出
- AI 辅助分析

优点是容易启动；缺点是客单价和规模天花板相对有限。

### 2.2 企业版

长期最值得重点验证的收入来源之一。

潜在客户：

- 投资机构
- 咨询公司
- 市场研究机构
- 网络安全团队
- 销售 / BD 团队
- 竞争情报团队
- 大型互联网企业

潜在能力：

- 企业 / 网站监控
- 竞争对手变化
- 技术栈变化
- 基础设施变化
- 企业关系图谱
- 历史情报
- 团队协作
- 企业级 API

### 2.3 API / 数据服务

把 SiteIntel 数据提供给其他系统：

- SaaS
- AI 应用
- 企业内部系统
- 数据平台
- 风控系统
- 研究平台

长期看，这一层可能比单纯网页流量更重要。

### 2.4 数据增值服务

- 行业数据库
- 企业名单
- 技术采用数据库
- 网站群数据库
- 市场研究数据集
- 定制研究
- 定制情报报告

### 2.5 AI 情报能力

当基础数据足够丰富后，可以提供：

- 企业画像
- 网站群发现
- 相似企业发现
- 技术趋势
- 成长信号
- 出海信号
- 公开互联网活动变化分析

AI 不应该脱离数据独立成为噱头，而应该成为数据资产之上的分析层。

## 3. 潜在的高价值客户方向

一个重要的长期方向是“企业成长与商业情报”。

例如持续观察一家公开可见的创业公司：

- 网站是否变化
- 产品是否增加
- 技术栈是否升级
- 基础设施是否扩张
- 招聘是否增加
- 是否增加国际化页面
- 是否出现新的品牌 / 产品
- 是否形成新的企业 / 网站关系

这些信号可以帮助研究人员更早理解企业的公开互联网活动变化。

注意：不得把公开推断包装成未公开内幕信息，也不应声称掌握企业内部规划。

## 4. 商业化路径

### 阶段一

先证明网站数据有使用价值。

### 阶段二

用历史、关系和监控提高留存。

### 阶段三

用企业版提高客单价。

### 阶段四

用 API / 数据服务扩大收入规模。

### 阶段五

形成多个垂直数据产品和子站。

## 5. 风险

- 数据采集成本
- 数据准确率
- 数据版权与再分发限制
- 隐私与合规
- 企业销售周期
- 客户获取成本
- 大型平台竞争
- 数据更新速度

因此不能只追求“收集越多越好”，而要建立可验证、可追踪、可复用的数据资产。

## 6. 长期商业定位

最终希望从“网站查询工具”升级为：

**互联网实体与企业情报数据公司。**

网站查询是入口，数据资产是底座，企业情报是高价值产品，API / 企业服务是商业化放大器。
