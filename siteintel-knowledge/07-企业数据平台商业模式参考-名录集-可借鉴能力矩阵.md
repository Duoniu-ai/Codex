## 1. 核心判断

名录集值得 SiteIntel 研究的地方，不是“企业名录”本身，而是它把企业基础数据加工成了多种可检索、可导出、可购买、可形成报告的产品。

其公开页面已经体现出以下产品化路径：

- 企业/法人维度查询
- 企业网站查询
- 地域、注册日期、行业等条件筛选
- 企业数据导出
- VIP 会员
- 企业调查报告
- 企业风险、管理、动态、详情等专题报告
- 行业企业名录
- 每日更新的数据服务

这说明一个重要商业规律：

> 原始企业数据的价值有限；“数据组织 + 关系发现 + 筛选 + 历史变化 + 报告 + 持续更新”才形成可销售的数据产品。

来源页面显示名录集提供按法人姓名查询企业、企业网站查询、VIP 下载、按注册日期/城市/位置/行业查询，以及异常经营、司法信用、核心人员、变更、专利、舆情招聘、招投标、疑似控制人/受益人等报告产品。其页面还标注数据每天更新。 citeturn0view0

## 3. SiteIntel 不应简单复制的部分

### 3.1 不做“另一个工商名录”

SiteIntel 的核心优势应继续保持在：

> Website → Infrastructure → Technology → Entity → Evidence → Intelligence

企业数据是扩展维度，而不是取代网站情报。

### 3.2 不直接照搬数据采集方式

国家企业信用信息公示系统是国家级企业信用信息归集公示平台，提供企业等市场主体信用信息的公示和查询。官方页面说明信息来自市场监管部门、其他政府部门及市场主体，并分别承担真实性责任。 citeturn0search4turn0search8

官方同时曾明确说明实名认证查询是为了在保障数据安全的同时满足正常查询需求，并提到防爬虫安全策略。因此，“页面公开可查询”不能直接等同于“允许无限制批量爬取”。 citeturn0search9

SiteIntel 应优先研究：

1. 官方开放数据/合法授权渠道
2. 数据合作/API
3. 合法公开数据来源
4. 在明确合规边界下使用公开页面数据

任何批量采集方案都需要单独进行来源、条款、隐私、数据使用权和商业化风险审查。

## 4. SiteIntel 的差异化方向

### 名录集

```text
企业数据
  ↓
查询 / 筛选 / 下载 / 报告
```

### SiteIntel

```text
企业
 ↓
官网 / Domain / IP / ASN / CDN / Technology
 ↓
企业身份 / 人员 / 投资 / 事件
 ↓
时间变化
 ↓
证据链
 ↓
情报
```

因此 SiteIntel 更适合定位为：

> **企业数字情报基础设施，而不是普通企业名录。**

## 7. 与 SiteIntel 未来子站生态的关系

企业数据底座可以向多个垂直产品复用：

- 企业官网数据库
- 企业技术栈数据库
- 新公司/新域名发现
- 创业公司情报
- 企业融资情报
- 企业上市前观察
- Logo / Brand 数据库
- APP / 小程序企业关联
- 招聘与技术趋势
- 企业数字资产监控
- 行业企业名录
- 企业风险观察

核心原则：

> **一套底层数据资产，多套垂直产品入口。**

## 8. 对 2.0 的影响

不建议为了加入企业数据而大规模重构当前 2.0。

2.0 后续小版本只需要提前保证架构能够容纳：

- Company Entity
- Person Entity
- Organization Relationship
- Event
- Evidence
- Source
- Observation History

具体大规模企业数据采集与企业情报产品，可以放到 2.x / 3.0。

## 9. 对未来商业化的启示

名录集验证了三类收入模式：

### A. 数据订阅

用户持续购买更新的数据访问权。

### B. 报告/查询付费

用户为一次高价值调查付费。

### C. 数据导出/API/B2B

企业客户按批量、接口或数据授权付费。

SiteIntel 可以进一步加入第四类：

### D. 持续监控与情报订阅

例如：

> “监控这 100 家创业公司的网站、技术、域名、基础设施、招聘、公开事件和企业变化；发生重要变化时通知我。”

这一层比单纯“查询一次企业”更容易形成持续收入。

## 10. 最终战略结论

名录集是一个很有价值的商业模式参考，但不是 SiteIntel 的终点。

SiteIntel 应吸收它的：

- 数据组织
- 关系查询
- 条件筛选
- 行业专题
- 数据下载
- VIP/订阅
- 企业报告
- 持续更新

同时形成自己的核心差异：

> **把企业静态信息与互联网公开资产、网站技术、网络基础设施、历史变化和证据链连接起来。**

长期目标不是“做一个更大的企业名录”，而是：

> **成为企业数字世界的可查询、可验证、可追踪情报层。**
