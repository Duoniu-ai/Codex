## 2. 第一屏最终结构（阅读顺序）

```
域名（H1 + 状态点）
↓
一句话结论（16px 强调面板，accent 左边框；无数据时如实降级为「目前可获取的公开信息有限」）
↓
最重要指标 chips：在线状态 · 主要技术 ×2 · 主要网络服务 · 近 30 天 N 项变化 · N 项值得重点关注
↓
主要 CTA：重新分析 · 监控 · 认领
```

## 3. 概览减 Dashboard 感

一级保留：当前状态（在线/HTTP）、网站描述、主要技术、主要网络服务、关键基础设施（CDN/托管/DNS/邮箱）。
二级下沉：分析记录（Investigation 细节）→ 折叠「分析记录（展开）」；实体快速入口 chips → 移到「它如何运行」底部弱化呈现。数据零删除。

## 4. 最近发生了什么：Top 3 + 折叠

- 按**现有 severity 字段**排序（critical>high>medium>low，再按时间倒序）——纯前台排序，不重新定义后端规则
- Top 3 渲染为强调卡（severity 色左边框 + 状态点 + 人化标题 + 日期 + 为什么值得看 + 「前后变化」可展开）
- 其余进入「查看全部变化（N）」折叠列表（保留全部真实 Event，时间线样式不变）
- 生产实测：wordpress.org 11 项变化 → Top 3 + 折叠 8；baidu.com 5 项 → Top 3 + 折叠 2；无变化站点不显示折叠入口

## 5. 值得关注：视觉权重提升

洞察网格整体包入 accent 色强调容器（边框 + 面板底色），与上下区块视觉区分；卡片保持 3B 的「结论 → 为什么 → 证据」结构，无 slug、无 rule ID、置信度在「为什么这样判断」展开区。

## 6. 关联探索：降后台感

相关网站（强证据表）仍为首层展示；关联图谱默认折叠为「查看关联图谱」——弱关系不再抢首屏注意力，展开后图谱/列表双视图能力完整保留。关系计算逻辑零改动。

## 7. 深入数据：全面折叠

「网站健康度」「行动路线」「搜索数据」「原始检测记录」四个子块全部默认折叠（`<details>`），每个都有明确的展开标签与数量提示；导出按钮保留在区域底部可见。普通用户打开页面不再看到任何原始数据；专业用户一键展开。
