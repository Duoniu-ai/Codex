## 10. Error State 统一

- 404：「目标不存在 / Target not found」→ **「页面不存在 / Page not found」** + 「该页面不存在或已移动…」+ 返回首页

- OG 分享卡：alt 与 tagline 同步新产品定位（"SiteIntel — Understand any website"；CJK 字体限制下 tagline 保持 ASCII）
